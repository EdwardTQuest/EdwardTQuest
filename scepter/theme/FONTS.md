# Fonts in `assets/`

| file | family | designer | licence |
|---|---|---|---|
| `scepter-cormorant.woff2`, `scepter-cormorant-italic.woff2` | Cormorant Garamond (Latin subset) | Christian Thalmann | SIL Open Font License 1.1 |
| `scepter-source-sans.woff2` | Source Sans 3 (Latin subset, variable) | Paul D. Hunt, Adobe | SIL Open Font License 1.1 |

Both are free to bundle and embed under the OFL (https://openfontlicense.org). They load as
"Scepter Serif" and "Scepter Sans" so they never collide with the theme's own fonts. Untick
"Load the fonts" in a section to use the theme's fonts instead.
